MOBILE APP — SERVICES PAGE PREMIUM UI/UX REDESIGN SPECIFICATION
==============================================================

Goal
----
Redesign the Services page of MyGarage into a premium automotive service marketplace experience. The page should feel trustworthy, fast, and easy to use — similar to a modern booking platform.

Prioritize:
- Fast service discovery
- Clear urgency hierarchy
- Minimal cognitive load
- Premium automotive feel
- Excellent mobile usability

Do NOT use gradients anywhere. Use only solid colors, clean surfaces, and professional spacing.


Overall Visual Direction
------------------------
The design should feel like a professional automotive app.

Avoid:
- Excessive decoration
- Large empty spaces
- Overly colorful interfaces
- Cartoon-like styling
- Gradient backgrounds

Use:
- Clean white/slate surfaces
- Strong typography hierarchy
- Rounded modern cards
- Subtle shadows
- Clear category prioritization
- High-quality spacing

The user should immediately understand:
"What service do I need and how quickly can I get it?"


PAGE STRUCTURE
==============


1. TOP HEADER / INTRO AREA
--------------------------

Replace the large hero card with a more compact premium welcome section.

Layout:

Left:
- Small circular wrench/car icon container
- Solid light blue background
- Blue icon

Right:
Small label:
"SERVICES"

Main heading:
"Find the right help for your car"

Supporting text:
"Book repairs, maintenance, recovery, and automotive services from trusted providers."

Keep this section compact. Do not consume too much vertical space.


2. SMART SEARCH
---------------

Place search immediately after the intro.

Design:
- Full width
- Height: 48-52px
- Rounded 14px
- Soft border
- Search icon left

Placeholder:

"Search services, repairs, or car problems"

Examples:
"flat tyre"
"engine problem"
"oil change"


When searching:
- Hide quick access
- Hide priority filters
- Show result count immediately


3. QUICK SERVICE ACTIONS
------------------------

Replace horizontal chips with a more useful quick-action grid.

Display:

2 columns

Cards:
- Height around 70px
- Rounded 14px
- White background
- Subtle border

Examples:

🚨 Emergency
Get help now

🔧 Repair
Fix my car

🔋 Battery & Tyres
Common issues

⛽ Fuel
Delivery help


Each card should feel tappable.

Do not use emojis as the only visual element. Use icons where possible.


4. SERVICE PRIORITY FILTER
---------------------------

Create a compact filter row.

Three selectable pills:

🔴 Urgent
🟢 Common
🔵 Optional


Style:
- Solid indicator dot
- Neutral background
- Border
- Active state changes border color

Do not make these visually dominant.


5. SERVICE CATALOG HEADER
--------------------------

"Automotive Services"

"13 categories"

"Filter"

with a filter icon.

This allows future expansion.
